Maple Street Dental (Fictional Demo) AI demo · fictional data only

Ana wants a cleaning. The assistant takes it from there.

This page tells one story in five chapters. Every step is a real request to a real API. The assistant can answer, check times, and prepare a booking. It never writes one until the caller says yes.

I

Ask

Ana is curious about the weekend. She types the way people talk, and the assistant answers from the clinic's own rules.

When a question is not covered, it says so. When the question is medical, it does not guess. It hands the caller to a person.

Try one of Ana's questions

II

Book

Ana picks a cleaning and a day. The assistant shows only times that are really open, then a preview of exactly what it will book.

Nothing is written until she confirms the preview.

III

Change

Plans change. To find a booking you need its code and the name it was made under. A code alone is not enough.

Changes inside 24 hours are passed to the front desk. The assistant does not make them itself.

A plot twist

When the question is medical, the story changes.

The assistant will not diagnose, advise on medicine, or guess at urgency. Emergency wording gets a 911 prompt first. Everything else goes to a person, with the front desk number.

IV

Listen

The same rules, spoken aloud. A voice agent calls the same endpoints, and reads each preview back before it acts.

Voice is optional. Without it, everything in this story still works from the text and forms above.

Checking voice configuration…

V

Ledger

Every action leaves one line behind: what happened, and which record it touched.

There are no names, no codes, and no transcripts in the ledger.

    A portfolio project. The clinic, the names, and the 555-01xx phone numbers are invented. Nothing here is medical advice, and no real patient data is used.
